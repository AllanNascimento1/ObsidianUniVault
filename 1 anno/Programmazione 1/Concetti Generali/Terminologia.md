## Coding
Il processo di conversione di un insieme di istruzioni in linguaggio parlato a un insieme di istruzioni in un linguaggio comprensibile ad un computer
## Programming
 L'insieme dei passaggi necessari per passare da una richiesta in linguaggio parlato a un insieme di istruzioni in linguaggio parlato. 
Programming è più complesso del coding e infatti comprende anche una parte importante di coding ma comprende anche altri fasi come Analisi, Testing, Development, Performance e ecc.
